# Desktop design

A three-pane control window: navigation, monitor workspace, and persistent sound inspector. The original pairing sheet and sourced input-information panel remain. Sound has no duplicate navigation page. Picture groups existing verified controls and new read-only color readings; Remote contains only a small key whitelist; Device shows queried power state.

Bright tokens: canvas #f5f5f7, surface #ffffff, ink #1d1d1f, secondary #6e6e73, action #006bdf. Night: canvas #1c1c1e, surface #2c2c2e, ink #f5f5f7, secondary #a1a1a6, action #57a4ff. System SF/Segoe UI type, left-aligned 13/15/24px hierarchy, quiet grouped rows. The volume wheel is the main expressive control. Real native window buttons sit in a unified draggable header.

The frontend-design skill informed the design review. Revised away from repeated dashboard cards toward a single input panel and a persistent inspector. Unsupported readings and controls are omitted. Computer output always retains provenance and input association. New readings do not imply verified write support.

Native scrolling stays intact. An overlay indicator has a 4px rounded thumb, expands on pointer approach, and fades after interaction. A wider hit area supports dragging; keyboard access and an always-visible option remain. Forced-colors mode falls back to the system scrollbar. No nested vertical viewport within the main content. Short 180–220ms feedback answers user actions and follows reduced-motion preferences.
