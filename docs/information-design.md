# Signal information and settings

Continue the existing frontend-design direction: canvas #e9edf2, surface #ffffff, ink #182330, muted #526171, blue #245cc5, verified #216347; SF Pro / Segoe UI. Left aligned, compact information grid below the input rail, then native disclosures for Sound, Picture, and Advanced capabilities.

The status preview remains the expressive element. Shrink it to make room for useful information, rather than adding another dashboard. Each value has a source and evidence scope. The same Refresh button updates independent monitor and computer snapshots; partial failures remain visible. Unsupported HDR and VRR are explicit unknowns, never inferred from a mode name.

Local displays use anonymous labels. An explicit input/display association is required before OS output can contribute to the current-input fields. Other inputs never borrow this computer's output mode. Settings use explicit Apply actions, no writes during slider dragging, no success until read-back, and picture-context checks around writes.
